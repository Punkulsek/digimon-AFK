# 관동 20지역 배경 승인안

**보관용 이전 후보 문서입니다. 현재는 사용자 요청에 따라 새로 제작한 20개 지역 배경을 적용했습니다. 아래 외부 이미지 배치안은 적용하지 않았습니다.**

아래는 실제 Pokémon Showdown 전투 배경입니다. 각 지역의 분위기에 맞춘 대체 후보이며, 해당 체육관·상트안느호·건물 내부를 정확하게 재현한 원작 지역 전용 그림은 아닙니다. 같은 배경을 여러 지역에 재사용하는 안입니다. 특히 상트안느호는 선박 내부 대신 해변, 체육관은 타입에 맞는 지형을 추천했습니다. 원작 장소와 일치하는 전용 배경을 원하면 이 배치안을 승인하지 않고 추가 후보를 요청할 수 있습니다.

첫 번째 열은 추천이며, 지역마다 총 3개 후보를 제시합니다. `추천 배치 승인` 또는 `상트안느호 H, 포켓몬타워 C, 나머지 추천`처럼 선택해 주세요. 승인 전에는 새 배경을 게임 런타임에 연결하지 않습니다.
