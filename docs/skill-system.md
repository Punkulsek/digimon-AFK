# 2단계 기술 시스템

`docs/skill-system-request.md`는 사용자 제공 원문입니다. `src/generated/skills.json`에는 공통 기술 131개와 도감번호 1~151의 배정이 있으며, 같은 이름의 기술은 동일한 효과·범위·충전시간을 공유합니다.

## 구현 구조

- `skills.js`: 공통 정의와 포켓몬별 배정 조회.
- `skill-runtime.js`: 게이지, 상태이상, 버프, 보호막, 피해·회복, 지연/지속 효과.
- `skill-moves.js`: 원문의 기술별 효과와 조건. 임의의 타입별 대체 공격을 추가하지 않습니다.
- `game.js`: 아군/적군 편성, 일반 공격, 전투 종료·보상·진행도. 화면 갱신과 별개로 0.05초 단위의 게임 시간으로 계산합니다.
- `skill-effects.js`: 대상별 이펙트. 지정된 pokeemerald-expansion 저장소 원본 파일과 출처는 `public/effects/sources.json` 참조.

## 전투와 저장

아군은 기존 최대 5마리 편성을 사용하고 적은 5마리로 등장합니다. 일반 전투 10회를 완료해야 보스에 도전하며, 보스와 부하까지 모두 쓰러뜨려야 클리어됩니다. 광역기로 동시에 쓰러진 적도 각각 한 번만 처치 집계됩니다.

던전도 같은 엔진에서 5마리와 전투합니다. 기존 던전의 합산 HP·공격력 예산은 중심 적과 부하에 나눠 적용하며, 보상과 단계 개방 규칙은 유지합니다.

일반 전투가 끝나면 아군 기술 게이지는 다음 전투로 이어지고, 전투별 상태이상·버프·예약 효과는 초기화됩니다. 이전 적에게 예약된 효과가 다음 적에게 넘어가지 않습니다. 보스 도전·패배 복귀는 기존 파티 회복 규칙을 따릅니다. 기술과 일시 상태는 저장 데이터에 복제하지 않으며, 기존 재화·성장·보유 개체·던전 기록은 그대로 불러옵니다.

## 명시되지 않은 항목의 적용 기준

- 저주의 보스 피해 상한: 사용자 승인에 따라 8초 동안 최대 HP의 총 1%.
- 별도 대상 우선순위가 없는 공격은 살아 있는 앞열부터 선택합니다. 범위 내 남은 대상이 적어도 피해를 재분배하지 않습니다.
- 잠듦은 일반 공격과 기술 사용을 막습니다. 게이지까지 정지한다고 명시된 최면술·버섯포자는 잠든 동안 충전도 정지합니다.
- 알낳기로 생성되는 보호막은 8초 유지합니다(원문에 지속시간 미지정).
- 복제 기술은 효과 수치를 85%/75%로 적용하며 원본 범위와 시간은 유지합니다.

기술 전투 상태의 저장 형식 변경이 없으므로 저장 초기화는 필요하지 않습니다.
