# 포켓몬 방치형 RPG — 2단계 기술 시스템 재설계

## 1. 기본 전투 규칙

- 아군 5마리 VS 적 5마리.
- 각 포켓몬은 일반 공격과 전용 기술 1개 보유.
- 기술 게이지가 시간에 따라 충전되어 100%에 도달하면 자동 발동.
- 기술 게이지 포켓몬 체력바 밑에 파란색바로 구성되어있다
- 스킬 가속은 기술 게이지 충전속도에 반영.
- 모든 공격 기술은 기존 방어력·방어 관통·급소 시스템과 연동한다.
- **같은 기술을 여러 포켓몬이 사용해도 되며, 기술명과 동일하면 효과·기본 충전시간·공격 범위도 동일하다.**

### 기술 범위

- 단일: 적 1명
- 중광역: 적 최대 3명
- 광역: 적 최대 5명
- 지원: 효과에 지정된 조건의 아군

중광역·광역 기술은 적이 적게 남아도 빈 대상의 피해를 다른 적에게 몰아주지 않는다.

### 상태이상

- 독: 기술별 지속시간에 걸쳐 최대 HP의 총 5% 피해. 보스에게는 최대 HP 1% 상한.
- 화상: 공격력 15% 감소.
- 감전: 공격속도 20% 감소.
- 잠듦: 일반 공격과 기술 사용 불가.
- 혼란: 일반 공격 시 20% 확률로 자신의 공격력 50%만큼 자신에게 피해.
- 반동: 기술에 명시된 만큼 HP 감소.

같은 상태이상은 중첩되지 않고 지속시간만 갱신한다. 별도 표기가 없다면 공격력 비례 피해는 시전자 공격력을 기준으로 계산한다.
