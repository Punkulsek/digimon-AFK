# 포켓몬 데이즈

브라우저 전체를 채우는 가로형 한국어 방치형 RPG. 전투 배경 위에 UI를 겹쳐 표시하며, 화면 크기가 바뀌어도 여백·테두리 없이 채웁니다. Vite + JavaScript ES 모듈이며 백엔드 없이 실행합니다.

## 실행

**가장 쉬운 방법:** 브랜치 ZIP을 다운로드해서 압축을 풀고, 최상위 폴더의 `play.html`을 Chrome 또는 Edge로 여세요. Node.js 설치나 터미널, `localhost` 서버 없이 바로 플레이할 수 있습니다. 인터넷 연결도 필요하지 않습니다.

포켓몬 이미지 302개와 배경을 HTML 안에 포함했습니다. `play.html` 하나만 복사해도 이미지·음악과 함께 플레이할 수 있습니다. 브라우저의 자동 재생 정책에 맞춰 첫 버튼 조작 후 음악이 시작됩니다. 오른쪽 상단 설정에서 소리를 조절하세요.

진행 상황은 같은 브라우저와 파일 위치에서 유지됩니다. 파일을 이동하거나 다른 브라우저로 열면 저장 데이터가 별도로 취급될 수 있습니다. 파일 실행 버전과 개발 서버 버전의 저장 공간도 서로 다릅니다. 브라우저가 로컬 파일 저장을 차단하면 게임은 실행되지만 저장할 수 없다는 안내가 표시됩니다.

### 소스 수정용 개발 서버

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 환경은 Node.js 24입니다.

```sh
cd /workspace/digimon-AFK
npm ci
npm run dev -- --port 5173
```

```sh
npm test           # 전투, 보스, 소환, 성장, 편성, 저장 검증
npm run test:e2e  # Chromium 브라우저에서 실제 UI 흐름 검증
npm run build     # 배포용 dist 및 더블클릭 실행용 play.html 생성
npm run preview   # 빌드 결과 확인
```

## 구현 범위

- 전투 배경이 브라우저 전체를 채웁니다. 왼쪽 상단 프로필, 상단 중앙의 작은 스테이지 표시, 오른쪽 상단 재화·설정과 하단 `포켓몬 | 홈 | 던전 | 소환`을 같은 너비로 분할한 연결 메뉴바만 표시합니다. 메뉴바는 좌우 끝부터 끝까지 100% 너비로 화면 바닥에 밀착되고, 4개 메뉴를 균등 배치합니다.
- 편성과 성장은 포켓몬 메뉴, 자동 전투·보스·배속·음악은 설정에서 조절합니다. 상단 스테이지 표시를 누르면 진행도·수동 보스 도전·기존 퀘스트 보상에 접근합니다. 기존 스테이지 전투 규칙은 유지하며, 던전 기록과 재료 보관 항목을 저장 데이터에 추가합니다.
- 5마리 파티, HP와 공격력, 자동 공격·반격·치명타 시각 효과, 1/2/3배속.
- 일반 적 10마리 처치 후 수동 또는 자동 보스 도전. 처치 포켓코인, 보스 다이아 100개, 다음 스테이지 자동 이동.
- 보스전 60턴 제한 또는 전멸 시 파티 회복 후 현재 스테이지 일반 사냥 복귀. 반복 실패를 막기 위해 자동 보스 도전 해제.
- 지역당 20개 스테이지. 상록숲에는 사용자가 선택한 배경 A를 적용하며, 다른 지역은 기존 배경을 유지합니다. 첫 4지역 이후 배경 이름은 순환하고 난이도는 계속 증가.
- 1회 300 / 10회 2,700 다이아 소환. 일반 50%, 고급 28%, 희귀 15%, 영웅 6%, 전설 1%. 등급 내 균등 확률. 중복은 개별 개체로 보관. 별도 천장 없음.
- 포켓몬 관리는 독립 전체화면 페이지입니다. 상단의 큰 도트 포켓몬·받침대 5개와 전체 전투력은 고정되고 상단 파티는 원래 전체 너비를 유지하고 하단 목록만 화면 너비 78%로 중앙 정렬됩니다. 좌우 여백은 목록과 같은 배경을 사용합니다. 카드 크기를 유지하는 자동 열 배치로 보유 목록만 내부 스크롤됩니다. 마지막 카드도 메뉴바에 가려지지 않습니다. 슬롯 교체·해제, 빈 슬롯 추가, 등급/레벨/전투력 정렬, 상세 성장(최대 100), 최소 1~최대 5마리 편성을 지원합니다.
- 초기 지급: 포켓코인 10,000, 다이아 10,000, 보유 포켓몬 6마리 중 5마리 편성. 최초 10마리 처치 퀘스트 보상 300 다이아.
- localStorage에 스테이지, 재화, 보유 개체, 레벨, 편성, 설정, 이상한사탕, 타입별 재료와 던전 클리어 기록 자동 저장. 보상·편성·성장 즉시 저장. 새로고침 시 복원.
- PokeAPI의 관동 151종 정적 스프라이트와 움직이는 도트, 숲 배경, 빛·입자·속성별 공격 효과, 등급별 카드와 순차 소환 연출.
- 사용자 제공 Oldale Town MP3 배경음악 자동 반복 재생, 공격·획득·성장·클리어 효과음. 배경음악/효과음 각각 음소거·볼륨 조절 및 저장. 숨겨진 탭에서는 오디오 일시정지.

## 포켓몬 이미지와 데이터

사용자 요청에 따라 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)의 실제 이미지를 포함했습니다. 카드에는 정적 PNG, 전장·상세·소환 배너에는 5세대 Black & White의 애니메이션 GIF를 사용합니다. 운영체제에서 동작 줄이기를 켜면 정적 이미지로 표시합니다. 로딩 실패 시 정적 이미지, 플레이스홀더 순으로 대체합니다.

정적 파일은 `public/pokemon/<전국도감번호>.png`, 애니메이션은 `public/pokemon/animated/<전국도감번호>.gif`입니다. CSS `object-fit: contain`과 `image-rendering: pixelated`로 원본 비율·픽셀을 유지합니다. 직접 제공한 이미지로 교체할 수도 있으며, `play.html`에 반영하려면 `npm run build`를 실행하세요.

다운로드 스크립트 `scripts/fetch-sprites.py`는 출처 커밋 `97a7832d307311c0e1c6ea9035308bf80cc94f81`을 고정하고 HTTPS 검증, 파일 형식 검증, SHA-256 기록을 수행합니다. 출처·해시는 `public/pokemon/sources.json`, 저작권 표기는 `ASSETS.md`에 있습니다. 모든 파일이 포함되어 있어 평소 실행·빌드 시 다시 다운로드하지 않습니다.

사용자가 첨부한 `pokeapi-master.zip`에서 관동 포켓몬 151종의 한글 이름, 타입, 분류, 키·몸무게, 원본 능력치를 추출해 `src/generated/kanto.json`에 연결했습니다. 151종 모두 소환 가능하며, 실제 API 서버를 설치하거나 실행할 필요가 없습니다. 기존 19종의 게임 밸런스는 유지하고, 추가 종의 게임 능력치와 등급은 원본 능력치에서 계산합니다. 전설·환상 포켓몬은 전설 등급입니다. 소환 확률과 전투 능력치는 이 게임의 자체 규칙입니다.

데이터 출처와 라이선스는 `public/POKEAPI-LICENSE.txt` 및 독립 실행 HTML 내부에 포함했습니다. 이후 이미지 추가 요청을 반영하여 별도 PokeAPI GitHub 스프라이트를 함께 제공합니다.

데이터 재생성(개발용, Python 3 필요):

```sh
python3 scripts/import-pokeapi.py /path/to/pokeapi-master.zip
npm run build
```

## 파일 구조

- `src/data.js`: 포켓몬, 등급, 이미지 경로, 지역 정의
- `src/generated/kanto.json`: 첨부 PokeAPI에서 추출한 관동 151종 데이터
- `play.html`: 설치 없이 바로 플레이하는 독립 실행 파일
- `scripts/build-standalone.mjs`: 빌드된 코드와 스타일을 독립 HTML로 묶는 스크립트
- `src/game.js`: UI와 독립된 상태·전투·소환·저장 로직
- `src/main.js`: 화면, 모달, 이벤트, 전투 연출
- `src/style.css`: 반응형 UI와 애니메이션
- `src/polish.css`: 숲 배경·카드·소환·전투 효과와 오디오 UI
- `src/fullscreen.css`: 전체 화면 전투 배경, 겹쳐 표시하는 HUD 및 하단 중앙 메뉴 위치
- `src/collection.css`: 연결 메뉴바, 전체화면 포켓몬 관리와 고정 파티 슬롯
- `src/audio.js`: 로컬 Web Audio 음악·효과음 엔진, 사운드 설정 저장
- `public/audio/oldale-town.mp3`: 사용자가 제공한 BGM (독립 HTML에도 내장)
- `public/scene/forest.svg`: 게임용으로 직접 제작한 숲 배경
- `tests/game.test.js`: Node 기본 테스트 러너 기반 회귀 테스트
- `tests/browser/game.spec.js`: Playwright 브라우저 회귀 테스트 (`CHROMIUM_PATH`로 브라우저 경로 지정 가능, 기본 `/usr/bin/chromium`)

## 현재 제한

서버 저장, 계정, 오프라인 누적 보상, 스킬·시너지, 결제는 포함하지 않습니다. 숨겨진 탭에서는 전투를 멈추며 복귀하면 재개합니다. 브라우저 저장소 삭제 시 데이터가 사라집니다. 전투 중 적 HP는 저장하지 않아 새로고침 시 같은 스테이지에서 새 적으로 재시작합니다. 로컬 데이터 수정 방지나 여러 탭 동시 실행의 상태 병합은 제공하지 않습니다. 개발 서버에서는 Google Fonts를 시도하고 연결되지 않으면 시스템 한글 글꼴로 대체됩니다. 독립 HTML은 외부 글꼴 요청 없이 시스템 글꼴을 사용합니다.

클라우드 작업은 이미 격리되어 있으므로 기존 체크아웃을 사용하세요. 사용자가 요청하지 않는 한 별도 Git worktree를 생성할 필요가 없습니다. 설치 파일은 유지되지만 개발 서버 프로세스는 새 세션에서 위 명령으로 다시 시작해야 합니다.

재화 아이콘은 사용자가 제공한 포켓코인·다이아 PNG 원본이며, 독립 HTML에도 내장됩니다.

## 던전과 성장

- 하단 메뉴의 던전 버튼으로 전체화면 선택 메뉴에 진입합니다. 홈의 별도 던전 버튼은 제거했으며 포켓몬 관리 화면 구조는 유지됩니다.
- 포켓코인 던전, 이상한사탕 던전, 타입별 진화재료 던전을 제공합니다. 진화재료는 18개 타입 선택 화면을 먼저 거칩니다.
- 각각 10단계이며 직전 단계 클리어 시 다음 단계가 열립니다. 입장 전에 적 전투력·HP·공격력과 예상 보상을 확인할 수 있습니다.
- 입장하면 기존 스테이지 전투 화면에서 현재 편성(최대 5마리)으로 자동 전투합니다. 일반 전투와 동일한 Battle 엔진, 배치, 공격·피격·데미지 연출을 사용하고 적 능력치와 보상만 던전 규칙을 적용합니다. 이전 일반 전투의 HP와 진행도는 보관했다가 던전 종료 시 복원됩니다. 기존 배속 설정이 적용되며 120턴 제한입니다.
- 포켓코인은 단계×500개, 이상한사탕은 단계×10개, 해당 타입 진화재료는 단계×3개를 승리 시 한 번 지급하고 즉시 저장합니다. 입장 비용 없이 반복 도전할 수 있습니다.
- 패배·중도 이탈은 보상이 없으며 재도전할 수 있습니다. 진행 중인 전투는 저장하지 않으므로 새로고침하면 중단됩니다. 이미 지급된 보상과 클리어 기록은 유지됩니다.
- 레벨업은 포켓코인 대신 이상한사탕만 소비합니다. 필요 수량은 현재 레벨÷5를 올림한 값이며, 상세 화면에 필요·보유 수량을 표시합니다. 신규 및 이전 저장의 초기 사탕은 0개입니다.
- 진화 재료는 획득·보관만 가능하며 진화 기능은 아직 없습니다. 기존 저장을 불러올 때 기존 재화·포켓몬·성장·편성·스테이지를 유지하며 새 필드를 추가합니다.
- 관련 코드: `src/dungeon-config.js`(종류·타입), `src/dungeon.js`(난이도·입장 조건), `src/game.js`(공통 전투·보상), `src/dungeon-ui.js`(화면), `src/dungeon.css`(스타일).

### 진화와 돌파

포켓몬 상세 화면에서 진화 조건과 돌파를 확인할 수 있습니다. 진화는 레벨,
일반 지역 클리어, 지정 타입 재료 조건을 모두 만족해야 하며 확인 후 실행합니다.
지역 N 클리어는 N-20 보스 처치(현재 스테이지 > N×20)를 뜻합니다.
관동 도감 내 진화 경로와 이브이의 세 분기를 지원하며, 경로별 요구 조건은
`src/growth.js`의 `EVOLUTIONS`에서 개별 조정합니다. 진화 재료는 진화 후 포켓몬의 타입을 기준으로 계산합니다. 복합 타입이면 각 타입에 해당 진화 단계의 요구 수량이 각각 필요하며 모두 충족해야 한 번에 차감됩니다. 요구 재료와 각 보유량은 상세 화면과 확인창에 표시됩니다.

돌파는 1~10단계에서 각각 동일 종 카드 1~10장을 소비하고 HP·공격력을
돌파당 15% 올립니다(10돌파 +150%). 같은 진화 계열의 미편성 Lv.1·0돌파 중복 카드는 자동으로 재료에 합산되며,
돌파 버튼을 누를 때만 필요한 수량을 소비합니다. 편성·육성 카드는 보호됩니다. 5개 별은 처음에는 빈 별,
1~5돌파에 금색, 6~10돌파에 왼쪽부터 보라색으로 전환됩니다.
진화 시 UID·레벨·돌파·파티 슬롯이 유지되며, 진화 후에도 같은 계열 재료를 공유합니다. 이브이의 분기 진화도 하나의 계열입니다.
기존 저장에서 돌파 필드가 없는 포켓몬은 0돌파로 처리합니다.

포켓몬 관리 화면에는 메인 메뉴 바로 위에 포켓몬·도감 하위 메뉴가 있습니다.
도감은 관동 151종을 번호순으로 표시하며, 진화와 재료 소비 이후에도 획득 이력을 보존합니다.
기존 저장의 과거 획득 기록은 복원할 수 없으므로 현재 보유 목록으로 초기화합니다.

### 관동 400스테이지 밸런스 패치

`src/stages.js`에 20개 지역 × 20스테이지의 지역별 일반 적·보스와 난이도를 정의합니다.
일반 적 HP는 초반 스테이지당 약 3.7%, 공격력은 약 2.7%부터 시작해 후반으로
갈수록 증가율이 완만해집니다. 지역 경계에서는 HP 1.5%·공격력 1%의 추가 상승이
있습니다. 적 방어력은 피해를 부드럽게 감소시키며, 던전의 기존 수치는 유지합니다.
매 스테이지 10마리를 처치하면 보스를 도전할 수 있고, 10번째는 중간 보스,
20번째는 지역 최종 보스입니다. 보스 실패 시 현재 스테이지에서 자동 사냥하고
자동 보스 도전은 OFF가 됩니다. 성장 후 게이지의 보스 버튼으로 재도전하거나
자동 도전을 다시 켤 수 있습니다.

400 최종 보스 클리어는 한 번만 기록·보상 지급하고 20-20에서 일반 사냥을 계속합니다.
이전 무한 진행 저장이 400을 넘었다면 400 완료 상태로 이관하며 재화·성장·편성은 유지합니다.
상단 중앙 게이지는 처치 수, 남은 적 수, 도전 준비/전투/전체 완료 상태를 표시합니다.

`node scripts/simulate-balance.mjs`로 실제 전투 엔진의 5마리 성장별 보스 결과를
재현할 수 있습니다. [시뮬레이션 결과](docs/balance-report.md)는 치명타·공격 순서
10개 시작 위치를 비교합니다. 재료 획득 시간 및 장기 플레이 경험은 별도 플레이테스트가 필요합니다.

관동 20개 지역에는 사용자가 요청한 새 도트 스타일 배경을 적용했습니다.
숲·각 타입 체육관·선박 갑판·산굴·유령탑·연구시설 등 장소별 배경이 자동으로 전환됩니다.
배경은 비율을 유지한 채 화면을 채우고, 기존 던전 배경은 던전 입장 시 표시됩니다.
`play.html`에는 모든 배경이 포함되어 오프라인에서도 실행됩니다.

[20개 배경 갤러리](docs/region-gallery.html)는 ZIP을 내려받은 뒤 브라우저로 열어 볼 수 있습니다.
`public/scene/regions/kanto-1.png`~`kanto-5.png`는 새로 생성한 배경 시트이며,
각 시트의 네 장면은 왼쪽 위·오른쪽 위·왼쪽 아래·오른쪽 아래 순서입니다.
`src/stages.js`의 각 지역 `art` 설정이 시트와 위치를 연결합니다.
이전 외부 이미지 후보 문서는 참고 기록으로만 보관하며 현재 지역 배경에 사용하지 않습니다.

### 소환 개편

소환은 독립 전체화면 페이지이며 1·10·30회 가격은 각각 다이아 100·1,000·3,000입니다.
`src/summoning.js`의 누적 임계값과 레벨별 확률표를 실제 추첨과 확률 안내에서 공유합니다.
기존 누적 `summons` 기록으로 Lv.1~10을 계산하므로 이전 기록을 초기화하지 않습니다.
최초 진화형만 소환하며, 계열 내 최종 종족값 최댓값 기준 400 미만 R,
400~499 SR, 500~599 SSR, 600 이상 SSR+로 분류합니다. 뮤츠는 SSR+입니다.
소환 등급은 기존 보유 목록의 성장용 등급과 별도로 관리합니다.

### 전체 강화
하단 강화 메뉴에서 공격력·방어력·HP를 각각 레벨당 0.5% 영구 강화합니다. 레벨·진화·돌파를 반영한 능력치에 강화 배율을 적용합니다. 아군 방어력은 종족 방어력에 레벨·돌파·강화 배율을 적용하고 피해는 공격력×400/(400+방어력)으로 계산합니다. 강화 구매는 현재 HP 비율을 유지합니다. 비용은 레벨마다 ceil(100×1.08^레벨)을 합산하며 +1/+10/+100/MAX를 지원합니다. 안전한 정수 범위를 넘는 비용은 구매 불가로 처리합니다. 기존 저장에는 강화 0레벨을 추가하며 구매 즉시 저장합니다.

### 18타입 진화재료 던전
노말·불꽃·물·풀·전기·얼음·격투·독·땅·비행·에스퍼·벌레·바위·고스트·드래곤·악·강철·페어리를 모두 제공합니다. 각 던전은 독립된 10단계와 해당 타입 재료 보상을 사용합니다. 기존 6타입 재료와 기록은 유지하며 새 12타입만 0으로 초기화합니다. 배경은 타입별로 새로 제작했고, 선택 목록은 내부 스크롤로 마지막 타입까지 접근할 수 있습니다.
진화 조건의 레벨·지역·단계별 수량은 그대로이며 재료 종류만 목표 포켓몬의 실제 타입에 연결합니다. 예: 리자몽은 불꽃 600개와 비행 600개, 망나뇽은 드래곤 800개와 비행 800개. 한 재료라도 부족하면 아무것도 소비하지 않습니다. 진화 후에도 레벨·돌파·파티·돌파 조각을 유지합니다.
